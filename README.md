# Git Lab 1

Моя перша лабораторна робота з Git та GitHub.

## Автор

ПІБ: Тютюнник Олександр Володимирович

Група: КТ-26-1/11, КТ-26п

## Мета роботи

Ознайомитися із системою контролю версій Git та платформою GitHub.

## Виконані завдання

- Перевірка встановлення Git.
- Початкове налаштування Git.
- Створення локального репозиторію.
- Створення README.md.
- Додавання файлу до індексу.
- Створення коміту.
- Створення віддаленого репозиторію.
- Завантаження проєкту на GitHub.

## Висновок

Під час виконання лабораторної роботи я ознайомився з основами Git та GitHub, навчився працювати з репозиторіями, додавати файли, створювати коміти та завантажувати зміни на GitHub.
